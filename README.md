## ⚔️ The 9 Competitive Arenas

MindForge features 9 fully interactive, playable logical dimensions:

### 1. ♟️ Board & Strategy
- **Reversi (Othello) Strategy Master**: 8x8 territory conquest with legal move indicators, directional disk flip animations, and Minimax AI with positional evaluation matrices.
- **Grandmaster Chess Tactics**: Tactical board with interactive pieces, FEN parser, Greek Gift sacrifice, and Mate-in-2 problem solvers.

### 2. 🖼️ Logic Puzzles
- **Picross (Nonogram) Forge**: 5x5 and 10x10 procedural pixel deduction grid with row/column run clues, fill/cross cell mechanics, error validation, and victory celebrations.
- **Einstein's Zebra Logic Matrix**: Interactive constraint elimination matrix with multi-sector clue deduction.

### 3. 🔢 Number Puzzles
- **Sudoku Master 9x9**: Full 9x9 board with difficulty grading, on-screen numpad, keyboard inputs (1-9, Delete), pencil notes candidate mode, conflict highlighting, and mistake counter.
- **2048 Mind Forge**: Smooth sliding tile physics with arrow/WASD keyboard controls, score multiplier, and high score tracking.

### 4. 🔤 Word Games
- **Wordle Forge**: 5-letter competitive word challenge with 6 attempts, color-coded feedback (Green/Yellow/Gray), virtual on-screen keyboard, and extensive offline dictionary.
- **Cryptogram Detective**: Substitution cipher puzzle featuring historical philosophical and scientific quotes with frequency analysis and letter mapping inputs.

### 5. 🧠 Memory Games
- **Quantum Simon Sequence**: 4-quadrant glowing cyber pads with harmonic synthesizer frequencies, accelerating tempo, combo multipliers, and sequence recall.
- **Dual N-Back Cognitive Trainer**: The scientific standard in cognitive enhancement—simultaneous 3x3 visual spatial grid tracking and auditory pitch/letter cues at N=2 difficulty.

### 6. 🔺 Pattern Recognition
- **Raven's Progressive Matrix IQ Challenge**: 3x3 visual shape progression grid (8 shapes shown, 1 missing) with rotational symmetry, element density invariants, and real-time IQ evaluation.

### 7. 🕵️ Deduction & Detective
- **Blackwood Manor Criminal Case Files**: Interactive mystery investigation with suspect dossiers, alibis, forensic evidence lockers, and formal accusation chamber.
- **Mastermind Hex-Code Breaker**: Cryptographic code deciphering in 8 attempts with Black (exact) and White (partial) indicator pin feedback.

### 8. ⚡ Speed & Reaction
- **Stroop Neuro-Reaction Test**: Color vs. Word semantic interference challenge with millisecond precision reaction timers and cognitive inhibition rating.
- **Reflex Target Aim Grid**: Fast-paced target clicking arena with shrinking life rings and accuracy metrics.

### 9. 🧭 Maze & Pathfinding
- **Procedural Labyrinth & Fog of War**: Procedurally generated mazes via Recursive Backtracker with keyboard movement (WASD/Arrows), collectible energy orbs, and dynamic torch lighting.
- **Pathfinding Algorithm Visualizer**: Real-time frontier node exploration engine comparing **A\*** (Manhattan heuristic), **Dijkstra**, and **Breadth-First Search (BFS)**.
